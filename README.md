Entry for the make.fun bounty **One Line to Your Younger Self**: a tiny
deterministic Node 22 program (`main.ts`, stdlib only, no network, no
wall-clock, no randomness) that writes one line to `/output/entry.txt`,
with a 1–200 character gate validation and a read-back self-check.

The line: skip the red bike at 14 — the brakes fail on Maple Street,
you break your left arm, and the cast is how you meet Maya, who still
steals your fries 20 years later.

## Run it

```sh
node main.ts [output-path]
```

With no argument it writes to `/output/entry.txt`. The first argument
(or the `OUTPUT_PATH` environment variable) overrides the output path
for local testing; a directory argument means `<dir>/entry.txt`.
